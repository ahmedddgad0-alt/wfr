موقع FREEWAVE
=============
1) ضع ملف APK النهائي داخل مجلد downloads وسمّه بالضبط: freewave.apk
2) افتح index.html محليًا للمعاينة.
3) ارفع محتويات هذا المجلد إلى استضافة موقع ثابت (مثل GitHub Pages أو Cloudflare Pages).
4) بعد النشر، زر "تحميل FREEWAVE" ينزّل downloads/freewave.apk مباشرة.

مهم:
- الموقع لا يحتوي على APK لأن ملف APK لم يُرفع في هذه المحادثة.
- لا ترفع ملف freewave-release.jks أو أي كلمات مرور إلى الموقع أو GitHub.
- اختبر رابط التحميل بعد النشر من هاتف Android.
- لا تضف ادعاءات مثل "آمن 100%" أو "يعمل على كل الأجهزة".
